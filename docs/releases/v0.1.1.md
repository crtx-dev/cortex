# Cortex v0.1.1

Cortex v0.1.1 is a stable public-preview release.

- Adopts the canonical Gantry multi-account authorization model with
  account-scoped credentials and TOTP identities.
- Adds the shared-layout `/manage/` console and adaptive instance launcher.
- Adds headless setup and confirmation-protected `reset --auth` and
  `reset --all` commands for scripted administration and recovery.
- Reports successful service lifecycle actions consistently.
- Pins the stable Gantry Core v0.1.0 module for reproducible standalone builds.

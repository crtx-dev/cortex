# Cortex API reference

The authoritative route list, method, CLI mapping, permission boundary, token scopes and schema names are generated in [`../generated/functional-coverage.md`](../generated/functional-coverage.md).

Every website-used functional operation in the manifest has an HTTP route. Service protocols and browser handshakes are marked explicitly and are not misrepresented as ordinary human CLI operations. CLI and browser calls reach the same HTTP/application authorization boundary; product-local direct commands are documented separately from HTTP operations.
